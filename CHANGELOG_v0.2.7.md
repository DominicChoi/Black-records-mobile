# v0.2.7 — Night, Weather & Lighting Pass

- Added time-of-day weather states: mist, clear, overcast, drizzle.
- Added smooth dusk/night/dawn overlay color changes.
- Added procedural drifting fog, cloud veil, drizzle streaks and night vignette.
- Village street lamps now turn on near dusk, flicker subtly, and fade at dawn.
- House window brightness follows time of day.
- Drizzle adds a wet-road tint and reflection streak.
- HUD weather text now uses Korean labels.
- Existing save format, quest IDs, NPC IDs, scene paths and mobile controls remain compatible.
- Save metadata version updated to 0.2.7; old saves remain loadable because loading is field-based.
