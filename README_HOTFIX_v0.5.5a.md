# 검은 기록 v0.5.5a — Interior Rendering Hotfix

## 수정 원인
v0.5.4 실내 시스템이 `interior_room.tscn`의 Node2D를 Main 월드에 직접 추가해,
Camera2D의 월드 변환을 그대로 받았습니다. 그 결과 1280×720 실내 배경이 화면 좌표가 아니라
3200×1600 월드 좌표로 취급되어 실내가 일부만 보이고 하단이 비어 보였습니다.
또한 야외 HUD와 실내 UI가 동시에 남아 `나가기` 버튼과 대화 UI가 중복되었습니다.

## v0.5.5a 수정
- 실내 배경을 월드 Node2D가 아니라 전용 CanvasLayer(layer 80)로 표시
- 1280×720 실내 이미지를 전체 화면 비율에 맞춰 표시
- 실내 진입 중 야외 월드/캐릭터/NPC/TopBar/미니맵/조이스틱/대화창/조사 버튼 숨김
- 실내 전용 제목/설명/나가기 버튼만 표시
- E 키와 나가기 버튼 모두 정상 퇴장
- 퇴장 시 원래 플레이어 좌표와 야외 UI 표시 상태 복원
- 경찰지소 위치를 대형 월드/미니맵 기준 (710, 855)로 통일
- 기존 구형 경찰지소 `change_scene` 진입과 새 InteriorController 중복 제거
- 프로젝트 창 제목을 v0.5.5a로 갱신

## 유지한 항목
캐릭터 이동, NPC 루틴, 미니맵, 날씨, 야간 효과, 세이브 구조 및 퀘스트 상태값은 변경하지 않았습니다.
