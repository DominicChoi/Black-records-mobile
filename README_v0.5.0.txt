검은 기록 v0.5.0 — RPG Overworld Expansion

이번 실행에서 실제로 완료한 것
1) 은령마을 월드를 1920x900에서 **3200x1600** 규모로 대폭 확장
2) 카메라 한계치/플레이어 시작 위치/NPC 동선/미니맵 범위를 모두 새 월드 기준으로 갱신
3) 중심 광장, 경찰지소, 여관, 수호당, 남쪽 호수, 동부 창고, 폐광 관리소, 북쪽 숲 입구를 포함한 **RPG식 대형 필드**로 재구성
4) 그래픽 밀도를 높이기 위해 산맥/숲/호수/다리/농지/광장/폐광 진입로/조명 효과를 추가
5) 미니맵에 랜드마크 + 현재 시야 박스 표시
6) 0.4.1 야간 추적 퀘스트 좌표를 대형 월드에 맞게 다시 조정
7) Android APK 로컬 빌드용 가이드 추가

적용
- 이 ZIP 내용을 현재 프로젝트 루트에 덮어쓰기
- 이미 0.4.1을 적용했다면 follow_quest_controller.gd는 새 버전으로 대체됨
- project.godot의 autoload에 NightPursuit 항목이 있는지 확인
- Godot Import 완료 후 F5

주의
- 이번 패치는 실질적으로 필드를 '큰 월드'로 넓히는 1차 패스입니다.
- 다음 패스는 북쪽 숲 / 폐광 외곽 / 경찰지소 실내를 별도 맵으로 분리해 진짜 지역 이동 구조로 만들 예정입니다.
