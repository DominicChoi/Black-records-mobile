검은 기록 v0.5.2 — Character Motion Pass

v0.5.0의 대형 월드/미니맵/야간 추적 구조를 유지하면서 캐릭터 이동 체감을 개선한 안전 패치입니다.

완료:
- 플레이어 가속/감속 튜닝
- 이동 속도에 따른 보행 주기 변화
- 좌우 체중 이동 + 상하 바운스 + 방향별 미세 기울기
- 플레이어/NPC 접지 그림자
- 조사 시 0.34초 상호작용 포즈와 시각 피드백
- NPC 보행 sway/bob 적용
- 장면/퀘스트 좌표/스프라이트 파일은 변경하지 않음

적용:
현재 v0.5.0 프로젝트의 scripts 폴더에 player.gd와 npc.gd만 덮어쓴 뒤 F5 실행.
