검은 기록 v0.5.4 — Interior Entry + NPC Life Pass

누적 기준: v0.5.3

이번 실행 완료
- v0.5.3에서 준비만 했던 경찰지소/마을회관/여관 실내 아트를 실제 입장 가능한 공간으로 연결
- 각 건물 앞 접근 시 '내부 조사 가능' UI 표시
- PC E키 / 모바일 입장 버튼으로 실내 진입 및 퇴장
- 실내 진입 중 월드/NPC/미니맵을 숨기고 플레이어 물리 이동을 일시 중지하여 기존 월드 좌표와 퀘스트 상태 보존
- NPC 대화를 시간대별 3종 변형으로 확장하여 반복 대사 감소
- 기존 한상철 추적 좌표, 북쪽 숲 완료 위치, 세이브 구조는 변경하지 않음

적용
v0.5.3 전체 프로젝트에 이 ZIP을 덮어쓰기.
주의: 기존 project.godot에 이미 [autoload] 섹션이 있다면 InteriorController 줄만 해당 섹션에 합쳐야 함.
